# Homepage & Section Image Briefs — AI Generation / Illustrator

Concrete, per-image prompt sheet for the 13 photographs currently placed on the
site. Each brief follows the framework in [`ai-image-prompts.md`](./ai-image-prompts.md).
Use the **Prompt** line as a paste-ready starting point for an AI image tool to
generate a reference, then rebuild/refine the final asset in Illustrator.

The current files in `public/images/` are licensed Pexels placeholders (see
`public/images/CREDITS.md`); replacing a file in place — same filename — swaps it
across the whole site with no code changes.

## Global brand direction (applies to every brief)

- **Palette:** deep navy `#0B1E33`, muted gold `#D4AF37`, warm cream `#F3E8D2`,
  near-black, white. Premium, minimal, editorial — never bright or saturated.
- **Mood:** confident, calm, expensive, understated. Lots of negative space.
- **Lighting:** directional, soft, dramatic single-source; deep shadows.
- **Always exclude:** human faces, recognisable people, readable text, real
  brand logos, watermarks, clip-art, lens flare, cheesy/generic stock-photo
  staging, cluttered desks, rainbow/pastel colour.
